## Core Principle

The goal is not "get as many backlinks as possible." It is to build a larger, more diverse, more relevant referring-domain profile over time through legitimate relationships, useful content, and earned citations. A single link from a relevant BC editorial publication is worth more than fifty identical directory submissions.

Before acting on any prospect ask: *Would this link make sense if Google did not exist?* If the answer is no, reject it.

## Lost and Broken Link Recovery

### Process

1. Run Semrush or Ahrefs → Lost Backlinks report monthly
2. For every lost link: check if the referring page still exists (404, moved, or changed content)
3. If the referring page exists but removed the link: note why (content changed, page edited, business closed)
4. If the referring page returns 404: the referring domain may have changed its own URL — check with a site search before outreach
5. If TowingNo.1's own target page URL changed: update the canonical or implement a redirect, then contact the referring site with the new URL
6. Check HTTP → HTTPS redirects: confirm all existing links to http://towingno1.com forward correctly to https://www.towingno1.com

### Unlinked Mention Recovery

Run a Semrush Brand Monitoring report or Google search for `"TowingNo.1" OR "Towing No 1" OR "towingno1.com" -site:towingno1.com` monthly. When a mention is found without a link, contact the publisher and politely ask them to add a link to the page they mentioned.

## Quality Control Checklist

Before adding any link or prospect to the pipeline, run through this list. If the answer to the final question is no, do not pursue.

1. Is the website real, with a genuine human audience?
2. Is it relevant to towing, roadside help, vehicles, BC, Surrey, automotive, transportation, or road safety?
3. Does it have organic traffic (not just a domain sitting on a parked page)?
4. Does the page that would link to TowingNo.1 provide value to users?
5. Is there a legitimate, non-paid method to earn the link?
6. Is the site free from obvious link-farm, PBN, or mass-outreach signals?
7. Is the specific target page on TowingNo.1 relevant to the referring page's topic?
8. Would the anchor text be natural in context?
9. **Would this link still make sense if Google did not exist?**
